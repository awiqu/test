# RedLogic для ИИ: как описывать схемы, процессоры и программы

Эти документы написаны так, чтобы языковая модель могла **с первого раза** выдать файл, который RedLogic примет без правок.
Во вкладке «Компьютеры → ИИ и документация» те же документы и готовые промпты можно скопировать одной кнопкой
(промпты автоматически подставляют ваш процессор, карту памяти и устройства).

| Что нужно сделать | Документ | Формат результата |
|---|---|---|
| Нарисовать логическую схему (для редактора и экспорта в `.litematic`) | [circuit-netlist.md](circuit-netlist.md) | текст «нетлист» (`input`, `имя = AND(a, b)`, `output`) |
| Спроектировать процессор и его набор команд | [computer-format.md](computer-format.md) + [rtl-reference.md](rtl-reference.md) | один JSON-файл `redlogic-computer` |
| Написать программу для уже выбранного процессора | [assembler-syntax.md](assembler-syntax.md) | текст на ассемблере |

## Общие правила для любой модели

1. **Отвечайте одним блоком кода** нужного формата (JSON — ` ```json `, ассемблер — ` ```asm `, схема — ` ```netlist `) без комментариев внутри JSON.
2. Если RedLogic вернул список ошибок — исправьте **только** их и пришлите файл целиком заново.
3. Не придумывайте инструкции, регистры, устройства и порты, которых нет в описании процессора. Всё, что можно использовать, перечислено в промпте.
4. Числа в ассемблере: десятичные `10`, шестнадцатеричные `0x0A`, двоичные `0b1010`, символы `'A'`. В JSON числа — обычные (или строкой `"0x1F"`).

## Конвейер от идеи до Minecraft

```
идея ──► промпт ──► ИИ ──► JSON / ассемблер / нетлист ──► RedLogic (проверка и симуляция)
                                                              │
        схема ─────────────────────────────► .litematic (редстоун-схема из гейтов)
        программа ─► ассемблер ─► образ ПЗУ ─► .litematic (ПЗУ из бочек: 1 бочка = 4 бита)
```

Что делает приложение, а что нет:

* ✔ симулирует процессор по вашему описанию команд, проверяет ассемблер, показывает дисплеи/светодиоды/клавиатуру;
* ✔ генерирует `.litematic` с ПЗУ из бочек (сила сигнала компаратора = значение 4-битной ячейки) — проверено на сервере 26.2;
* ✔ генерирует `.litematic` для логических схем (гейты на редстоуне) — также проверено на сервере;
* ✘ **не** синтезирует из набора команд физический процессор из редстоуна — процессор вы собираете из схем (декодер, АЛУ, регистры — в редакторе схем) и подключаете к ПЗУ-бочкам.
