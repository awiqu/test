# Формат логической схемы (нетлист)

Нетлист — простой текст. Его можно вставить в редактор схем («Схемы → ⋯ → Вставить схему от ИИ»); RedLogic сам расставит гейты слева направо
и проложит провода. Затем схему можно проверить таблицей истинности и экспортировать в `.litematic`.

## Синтаксис

```netlist
# комментарий (также допустим //)
circuit "Полусумматор"          # необязательно, только название
input a b                       # входы (рычаги), порядок = порядок сверху вниз
s  = XOR(a, b)                  # имя = ТИП(вход1, вход2, ...)
c  = AND(a, b)
output sum   = s                # выход (лампа) с именем ← сигнал
output carry = c
```

* Одна команда на строку. Пустые строки и комментарии игнорируются.
* **Имена** сигналов: латинские буквы, цифры и `_`, первый символ не цифра. Регистр важен. Нельзя называть сигнал `input`, `output`, `in`, `out`, `circuit`.
* Имена выходов (`output имя = …`) живут отдельно от имён сигналов.
* Сигнал можно использовать **раньше**, чем он объявлен (обратные связи — триггеры, защёлки).
* Один сигнал можно подавать на сколько угодно входов.

## Типы гейтов

| Тип | Входов | Значение |
|---|---|---|
| `NOT(a)` (`INV`) | 1 | инверсия |
| `BUF(a)` (`BUFFER`, `REPEATER`, `DELAY`) | 1 | повторитель; `BUF(a, delay=3)` — задержка 1…4 тика |
| `AND(a, b, …)` | 2–4 | И |
| `NAND(a, b, …)` | 2–4 | И-НЕ |
| `OR(a, b, …)` | 2–4 | ИЛИ |
| `NOR(a, b, …)` | 2–4 | ИЛИ-НЕ |
| `XOR(a, b, …)` | 2–4 | 1 при нечётном числе единиц |
| `XNOR(a, b, …)` | 2–4 | 1 при чётном числе единиц |

Нужно больше 4 входов — соберите дерево из нескольких гейтов. Констант (0/1) нет: ноль можно получить как `AND(a, NOT(a))`, единицу — `OR(a, NOT(a))`.

## Правила для компактного результата в Minecraft

1. Не создавайте лишних гейтов: каждый — это блоки и провода. Предпочитайте `NAND`/`NOR`/`NOT`, они дешевле всего.
2. Не используйте больше ~40 гейтов в одной схеме (больше — компилятор может не успеть проложить провода).
3. Порядок `input` определяет нумерацию рычагов; порядок `output` — ламп.

## Типичные ошибки (RedLogic сообщит номер строки)

| Ошибка | Исправление |
|---|---|
| `Неизвестный тип гейта «FOO»` | используйте типы из таблицы выше |
| `Сигнал «zz» не объявлен` | опечатка в имени или не объявлен `input` |
| `AND: нужно 2–4 входов` | у AND/OR/NAND/NOR/XOR/XNOR от 2 до 4 аргументов |
| `Имя «a» уже объявлено` | у каждого сигнала своё имя |
| `Нет выходов` | добавьте `output имя = сигнал` |

## Примеры

**Мультиплексор 2→1** (`y = s ? b : a`)

```netlist
input a b s
ns = NOT(s)
t0 = AND(a, ns)
t1 = AND(b, s)
y  = OR(t0, t1)
output y = y
```

**SR-защёлка** (две NOR с перекрёстной связью)

```netlist
input s r
q  = NOR(r, nq)
nq = NOR(s, q)
output Q = q
output NQ = nq
```

**Полный сумматор**

```netlist
input a b cin
x1 = XOR(a, b)
sum = XOR(x1, cin)
a1 = AND(a, b)
a2 = AND(x1, cin)
cout = OR(a1, a2)
output S = sum
output Cout = cout
```
