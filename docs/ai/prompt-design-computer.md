## Что нужно сделать

1. Подбери характеристики (`spec`): разрядность, регистры/аккумулятор, ширину команды, размеры ПЗУ и ОЗУ, флаги, операции АЛУ, стек, устройства.
   Компьютер собирается из редстоуна руками, поэтому **чем проще, тем лучше**: типично 4–8 бит данных, 8–16 бит команда, ПЗУ 16–64 слова.
2. Придумай набор инструкций (`instructions`): для каждой — мнемоника, код операции, формат операндов, описание, псевдокод и исполняемый RTL-код (`code`).
   Обязательно: `NOP`, `HLT`, загрузка константы, доступ к памяти и портам устройств, арифметика/логика, безусловный и условные переходы
   (+ `CALL`/`RET`/`PUSH`/`POP`, если включаешь стек).
3. Проверь себя по контрольному списку из документа формата (опкоды влезают в `opcodeBits`, команды влезают в `instrBits`, RTL использует только выбранные флаги и операции АЛУ).
4. По желанию добавь в `programs` 1–3 коротких демонстрационных программы на ассемблере (синтаксис ниже).
