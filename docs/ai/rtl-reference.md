# RTL: язык описания инструкции

`code` инструкции — несколько операторов, выполняемых по порядку. Оператор — одна строка (или несколько через `;`). Комментарии — `// …`.
Все значения — целые без знака шириной `dataBits` (переполнение отбрасывается), если не сказано иное.

## Что можно читать и писать

| Имя | Чтение | Запись | Смысл |
|---|---|---|---|
| `R[i]` | ✔ | ✔ | регистр с номером `i` (только `arch: register`) |
| `A` | ✔ | ✔ | аккумулятор (только `arch: accumulator`; это `R[0]`) |
| `M[a]` | ✔ | ✔ | память данных по адресу `a` — ОЗУ **или порт устройства** (побочные эффекты как у реального порта) |
| `PC` | ✔ (адрес текущей инструкции) | ✔ (переход) | счётчик команд; запись вступает в силу после инструкции |
| `SP` | ✔ | ✔ | указатель стека (нужен `stack.enabled`) |
| `Z C N V` | ✔ | ✔ | флаги (только выбранные в `spec.flags`) |
| `t0 t1 t2 t3` | ✔ | ✔ | временные переменные внутри одной инструкции (в начале = 0) |
| `rd rs rt imm addr target off` | ✔ | ✘ | поля инструкции из `format` |
| `W`, `MASK` | ✔ | ✘ | `dataBits` и `2^dataBits − 1` |
| имена портов (`LEDS`, `TXT`, …) | ✔ | ✘ | числа-адреса портов |

## Операторы

* Присваивание: `=`, `+=`, `-=`, `*=`, `&=`, `|=`, `^=`, `<<=`, `>>=`.
* Условие: `if (выражение) оператор` и `if (…) { … } else { … }`; значение ≠ 0 считается истиной.
* Вызов функции как оператор: `halt()`, `push(x)`, `call(t)`, `ret()`, `skip()` и т. д.

## Выражения

Числа: `10`, `0x1F`, `0b1010`. Операции (по убыванию приоритета): унарные `! ~ -`; `* `; `+ -`; `<< >>`; `< <= > >=`; `== !=`; `&`; `^`; `|`; `&&`; `||`; тернарное `c ? a : b`.

## Функции АЛУ (меняют флаги!)

Операция разрешена, только если выбрана в `aluOps`. Флаги обновляются **только если они есть в `spec.flags`**.

| Функция | `aluOps` | Результат | Флаги |
|---|---|---|---|
| `add(a, b)` / `add(a, b, cin)` | ADD | `a + b (+ cin)` | Z N C(перенос) V |
| `sub(a, b)` | SUB | `a − b` | Z N C(**заём**: `a < b`) V |
| `and(a, b)` `or(a, b)` `xor(a, b)` | AND OR XOR | побитово | Z N, C=0, V=0 |
| `not(a)` | NOT | `~a` | Z N, C=0, V=0 |
| `shl(a)` `shr(a)` `asr(a)` `rol(a)` `ror(a)` | SHL SHR ASR ROL ROR | сдвиг на 1 бит; `shl(a, n)` — на `n` бит | Z N, C = последний выдвинутый бит |
| `inc(a)` `dec(a)` `neg(a)` | INC DEC NEG | `a+1`, `a−1`, `−a` | Z N C V |
| `mul(a, b)` | MUL | младшие `dataBits` бит произведения | Z N, C=1 при потере старших бит |

`sub(a, b)` можно вызвать как оператор, чтобы **только выставить флаги** (сравнение): `sub(R[rd], R[rs])`.

## Вспомогательные функции (флаги не трогают)

| Функция | Смысл |
|---|---|
| `mask(x)` | `x` по модулю `2^dataBits` |
| `sext(x)` | число со знаком: 0xFF → −1 (для сравнений/смещений) |
| `msb(x)` / `lsb(x)` | старший / младший бит |
| `lt_s(a, b)` | 1, если `a < b` как знаковые числа |
| `pop()` / `peek()` | значение с вершины стека (с удалением / без) |

## Управление

| Оператор | Смысл |
|---|---|
| `halt()` | остановить процессор |
| `nop()` | ничего |
| `push(x)` | `SP = SP − 1; M[SP] = x` |
| `call(t)` | `push(PC + 1); PC = t` |
| `ret()` | `PC = pop()` |
| `skip()` | пропустить следующую инструкцию (`PC = PC + 2`) |
| `setZN(x)` | выставить `Z` и `N` по значению `x` |
| `setC(x)`, `setV(x)` | выставить флаг `C` / `V` |

## Типовые инструкции (копируйте как образец)

| Мнемоника | `format` | `code` |
|---|---|---|
| `LDI rd, imm` | `rd,imm` | `R[rd] = imm` |
| `MOV rd, rs` | `rd,rs` | `R[rd] = R[rs]` |
| `LD rd, addr` | `rd,addr` | `R[rd] = M[addr]` |
| `ST addr, rs` | `addr,rs` | `M[addr] = R[rs]` |
| `LDR rd, rs` (косвенная загрузка) | `rd,rs` | `R[rd] = M[R[rs]]` |
| `ADD rd, rs` | `rd,rs` | `R[rd] = add(R[rd], R[rs])` |
| `ADC rd, rs` | `rd,rs` | `R[rd] = add(R[rd], R[rs], C)` |
| `SUB rd, rs` | `rd,rs` | `R[rd] = sub(R[rd], R[rs])` |
| `CMP rd, rs` | `rd,rs` | `sub(R[rd], R[rs])` |
| `CMPI rd, imm` | `rd,imm` | `sub(R[rd], imm)` |
| `INC rd` | `rd` | `R[rd] = inc(R[rd])` |
| `SHL rd` | `rd` | `R[rd] = shl(R[rd])` |
| `JMP target` | `target` | `PC = target` |
| `JZ target` | `target` | `if (Z) PC = target` |
| `JC target` | `target` | `if (C) PC = target` |
| `BNE off` (относительный) | `off` | `if (!Z) PC = PC + off` |
| `CALL target` | `target` | `call(target)` |
| `RET` | — | `ret()` |
| `PUSH rs` | `rs` | `push(R[rs])` |
| `POP rd` | `rd` | `R[rd] = pop()` |
| `HLT` | — | `halt()` |
| `LDA addr` (аккумулятор) | `addr` | `A = M[addr]` |
| `ADD addr` (аккумулятор) | `addr` | `A = add(A, M[addr])` |
| `SKZ` (пропустить следующую, если ноль) | — | `if (Z) skip()` |

## Частые ошибки

| Сообщение | Причина |
|---|---|
| `Поле «imm» не входит в формат инструкции` | `imm` используется в `code`, но не указан в `format` |
| `Операция АЛУ ADD (add) не выбрана в характеристиках` | добавьте `"ADD"` в `spec.aluOps` или не используйте `add` |
| `Флаг C не выбран в характеристиках` | добавьте флаг в `spec.flags` |
| `Имя «A» — только для аккумуляторной архитектуры` | в регистровой машине используйте `R[...]` |
| `Неизвестное имя «X»` | опечатка; доступны только имена из таблицы выше |
| `… нельзя использовать внутри выражения` | `halt()`, `push()`, `call()` — операторы, а не значения |
